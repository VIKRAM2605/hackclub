# Cooking Sim

## About
**Cooking Sim** is a time-management cooking game developed with HTML, CSS, and JavaScript, using the HTML5 `canvas` for rendering.

The game starts off slow and easy, but the difficulty picks up as more customers arrive. You must manage cooking stations, buy upgrades from the shop, and serve customers before their patience runs out.

**Game Mechanics:**
*   **Health:** If you fail to serve a customer within the timeframe, you lose a heart.
*   **Game Over:** If you lose 2 hearts, the game ends, prompting you to retry or quit.
*   **Shop:** Use your earnings to buy upgrades to help you survive longer.

## Controls

| Action | Input |
| :--- | :--- |
| **Movement** | WASD or Arrow Keys |
| **Interact (Stations)** | E |
| **Interact (NPCs/Customers)** | F |
| **Open Shop** | Click Shop Icon |
| **Cook Food** | Click Uncooked Food Icon (at station) |
| **Pick Up Cooked Food** | Click Cooked Food (in slot) |
| **Discard Food** | Click Cooking Food (in slot) |

## Built With
*   **HTML5 Canvas** - For rendering the game loop and art.
*   **Vanilla JavaScript (ES6)** - Game logic, physics, and collision detection.
*   **CSS3** - UI overlay and styling.

## How to Run Locally
If you want to modify the code or run it on your machine:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/VIKRAM2605/hackclub.git
    ```
2.  **Navigate to the folder:**
    ```bash
    cd hackclub
    ```
3.  **Run the game:**
    Simply double-click `index.html` or use the "Live Server" extension in VS Code.
